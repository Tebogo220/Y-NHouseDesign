#My Website and A Website Server

A Node.js server that serves a website and includes basic authentication, file uploads, and an image gallery.

##Features
-Serves static HTMl file 
(`index.html`,`Admin.html`,`contact.html`,`gallery.html`).
-Handles file uploads and stores them in an `uploads` folder.
-Basic authentication for admin-only routes.
-Displays uploaded images via an API.
-Allows deletion of uploaded images.
